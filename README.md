# portfolio-website

Website for my portfolio.

## GitHub Pages Deployment

This portfolio website is automatically deployed to GitHub Pages using GitHub Actions.

### Setup Instructions

1. Go to your repository's Settings → Pages
2. Under "Build and deployment", select:
   - **Source**: GitHub Actions
3. The website will be automatically deployed when changes are pushed to the `main` branch

The workflow file is located at `.github/workflows/pages.yml` and handles the deployment automatically.

### Local Development

To view the website locally, simply open `index.html` in your web browser.

## Features

- Responsive design that works on desktop and mobile
- Modern, clean layout
- Sections for About, Projects, and Contact
- Smooth navigation with sticky header
